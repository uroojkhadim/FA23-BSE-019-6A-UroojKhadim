# Assignment: Online Food Ordering System

## Course: Undergraduate Web Development

### Assignment Overview
This assignment requires you to build an "Online Food Ordering System" using an MVC framework of your choice. The project is divided into four phases, each focusing on specific learning objectives. Follow the instructions in the Lab Manual to complete each phase.

---

## Assignment Tasks

### Phase 1: Models & View Generators (Scaffolding)
- Create `MenuItem` and `Order` models.
- Use the framework's scaffolding tools to generate CRUD templates.
- Submit the generated code and screenshots of the working CRUD views.

### Phase 2: Bootstrap Integration
- Enhance the generated templates using Bootstrap.
- Ensure the layout is responsive and uses Bootstrap components (e.g., `Cards`, `Navbar`, `Buttons`).
- Submit the updated templates and a video demonstrating the responsive design.

### Phase 3: REST Principles & Method Selection
- Map UI actions to the correct HTTP methods (GET, POST, PUT, DELETE).
- Document how your API design adheres to REST principles.
- Submit a document with HTTP method mappings and REST principles explanation.

### Phase 4: Resource & URI Design
- Design RESTful API endpoints with proper URI structure.
- Submit a list of your API endpoints.
